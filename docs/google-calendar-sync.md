# Google Calendar ↔ LifeSims 3D (scene)

Интеграция работает в браузере напрямую через Google Identity Services и Google Calendar API. Не требует серверной части и не сохраняет access token в localStorage или JSON-бэкапах. Сам Google Calendar ChatGPT не передаёт разрешение стороннему сайту.

## Подключение (на каждом устройстве)

1. В Google Cloud Console создай проект либо выбери существующий; включи **Google Calendar API**.
2. Настрой **OAuth consent screen** и, если приложение в режиме Testing, добавь свою почту в **Test users**.
3. Создай **OAuth 2.0 Client ID → Web application**. Укажи **Authorized JavaScript origins** = `https://ansitnikkodland-alt.github.io` (без пути /lifesims-web/scene/). Не публикуй client secret.
4. Открой HTTPS-страницу `https://ansitnikkodland-alt.github.io/lifesims-web/scene/`, выбери вкладку **Мероприятия**, вставь Client ID и нажми **Подключить Google**.
5. По умолчанию стоит безопасный режим **Google → LifeSims** (только чтение). Для двустороннего обмена переключи режим и подключи Google повторно, чтобы подтвердить право записи.
6. Нажми **Проверить изменения**, прочитай список, затем **Применить изменения**. Перед первой синхронизацией экспортируй JSON в разделе резервной копии.

## Реализовано

- Чтение событий основного календаря (без доступа к другим календарям), окно от 14 дней назад до 400 дней вперёд.
- Создание локальной копии не привязанных событий; привязка уже существующих совпадающих записей во избежание дублей.
- Двусторонняя синхронизация с явным подтверждением изменений: добавление новых событий и обновление существующих.
- Сопоставление по Google event ID, сохранение etag и контроль локальных/удалённых изменений. Если оба экземпляра изменились — конфликт пропускается.
- Выбор дней недели при локальном еженедельном повторе переносится в Google через RRULE:BYDAY. Новые события создаются с часовой зоной браузера.
- Локальные записи и связь с Google сохраняются в текущем JSON-бэкапе. OAuth access token в него не входит.
- Удаления не распространяются ни в одну сторону. Любая запись в Google происходит только после нажатия «Применить изменения».

## Ограничения

- Автоматической фоновой синхронизации нет: пользователь нажимает кнопку вручную. OAuth токен действует ограниченное время и хранится только в оперативной памяти вкладки.
- Поддерживаются только события с временем; целодневные, сложные повторы (например, ежемесячные), индивидуально перенесённые экземпляры серий и исключения пока не синхронизируются полноценно. Индивидуально отменённые повторения Google могут отображаться в локальной еженедельной серии: сверяйся с Google, если нужны исключения.
- Параметры событий, которых нет в LifeSims (участники, описание, напоминания, местоположение), не импортируются. При PATCH сохранённые Google-поля, не указанные в запросе, обычно не меняются, но это следует проверить на тестовом календаре.
- За один запуск обрабатываются до шести страниц по 2 500 событий и до 100 серий повторов. При превышении лимита операция прерывается без частичного применения.
- При несовпадении часового пояса браузера и часового пояса повторяющейся серии импорт этой серии пропускается, чтобы не исказить время. Локальные даты форматируются в часовом поясе устройства.
- При ошибке посередине записи уже применённые операции не откатываются; повторный запуск требует нового предварительного просмотра.
- Вход Google внутри установленной PWA на Android может требовать открытие страницы в обычном Chrome, если всплывающее окно блокируется.

## Проверка

- Синтаксис встроенного JS, google-calendar.js и service worker проверен.
- Смоделированы токены с разными OAuth scope, загрузка и импорт событий, запись нового события Google и фиксация сопоставления с локальной записью.
- Реальная OAuth-авторизация и запись в личный Google Calendar **не проверены** — нужен Client ID и действие пользователя.

Документация API: [Google Identity Services token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model), [Google Calendar JavaScript quickstart](https://developers.google.com/workspace/calendar/api/quickstart/js), [Google Calendar events](https://developers.google.com/workspace/calendar/api/v3/reference/events).
