🔎 Проверка прежних записей

Проверка не меняет прогресс. Показывает только доступные сохранения LifeSims в этом браузере на этом сайте. Сохранения другого браузера или адреса здесь не появятся.

Локальное сохранение

Записи хранятся в браузере этого устройства и этого адреса. При очистке данных браузера они могут исчезнуть. Перед обновлением сохрани JSON.

HTML содержит оформление и функции, но сохраняет прогресс отдельно от веб-сайта. Переноси данные через JSON.

Восстановить данные

Выбери резервную копию JSON. Данные не заменяются до подтверждения.

Перед импортом скачай текущую резервную копию JSON. Если файл LifeSims открыт через content://, хранилище браузера может быть недоступно — импортируй через HTTPS-сайт.

Совместимость

При первом открытии на опубликованном сайте приложение пытается скопировать данные старого LifeSims без изменения оригинала. При открытии скачанного HTML-файла эти данные автоматически не доступны — используй экспорт/импорт.

Oura доступна в «Потребностях»: подключение требует регистрации OAuth-приложения и разрешения владельца аккаунта. Health Connect, ZenMoney, системные уведомления и автоматическое изменение тела персонажа ещё не реализованы. Google Calendar работает только после настройки OAuth и разрешения доступа.
