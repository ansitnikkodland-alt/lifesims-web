# LifeSims — локальный Android-компаньон экранного времени

Неофициальная часть самого проекта LifeSims, не интеграция с API StayFree.

1. Установить собранный APK на Android (или собрать через Android Studio, JDK 17, SDK 35).
2. Открыть приложение **LifeSims · Экранное время**, разрешить «Доступ к статистике использования» (Usage Access).
3. Нажать «Запустить локальный мост», скопировать код сопряжения.
4. В уже установленном веб-LifeSims открыть «Календарь → Импорт экранного времени», вставить код и включить автообновление.
5. Оставить компаньон запущенным (видно системное уведомление). Остановить можно из приложения или уведомления.

Браузер отправляет запрос на `http://127.0.0.1:18765/v1/usage?days=7`.
Порт открыт **только на 127.0.0.1** — недоступен по Wi-Fi, мобильной сети и из интернета.
Запрос разрешён только источнику `https://ansitnikkodland-alt.github.io`, требует случайного кода сопряжения.
Android-компаньон **не отправляет данные на сервер**, не запрашивает Accessibility и не меняет ничего в StayFree. Данные PWA остаются в исходном браузере.

Пока LifeSims открыт, обновление выполняется при открытии, возвращении на вкладку и примерно раз в 15 минут. В фоне браузера синхронизация может откладываться, но Android хранит данные использования и они считываются при следующем открытии (до 7 дней). Сервис компаньона — foreground service с постоянным уведомлением, который Android может завершить при ограничениях питания. После перезагрузки при необходимости запусти его снова.

Важно: браузер может запросить разрешение на локальную сеть либо заблокировать соединение с localhost согласно своим правилам. Проверяй на своём Android. Функция не переносит автоматически статистику StayFree с других устройств.

Дневные минуты получаются из `UsageStatsManager.queryUsageStats(INTERVAL_DAILY,...)`. Это отчёт Android об активном приложении, не точные времена сессий и не измерение концентрации. Данные о приложениях чувствительны: устанавливай APK только из собственного проверенного GitHub Actions артефакта.

Сборка CI: `.github/workflows/lifesims-android-companion.yml` → Actions → Build LifeSims Android companion → артефакт `lifesims-screen-time-debug-apk`.
